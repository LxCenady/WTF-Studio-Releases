# WTF Studio

WTF (Worldwide Teachers Friend) Studio: past questions, papers, marking and marks for teachers.
WTF (Worldwide Teachers Friend) Studio：给老师用的找题、组卷、批改和成绩工具。

This repository only holds the installers. Studio checks it for updates and installs them on request.
这个仓库只放安装包。Studio 会从这里检查更新，经你同意后自动安装。

## Download / 下载

**Windows 10 / 11:** [**WTF-Setup.exe**](https://github.com/LxCenady/WTF-Studio-Releases/releases/latest/download/WTF-Setup.exe)

Double-click it; it installs into your user folder, no administrator rights needed. The SHA-256 of every file is in
`SHA256SUMS.txt` on each release.
双击安装，装在你的用户目录，不需要管理员权限。每个版本都附有 `SHA256SUMS.txt`。

## Before you start / 开始之前

- Studio needs a **WTF account with the teacher plan** (beta accounts are set up by us).
  使用 Studio 需要开通了教师档的 **WTF 账号**（内测账号由我们开通）。
- On the first start you install a subject pack and provide that course's SCSA past papers (not shipped, for
  copyright reasons); the question bank is then built on your computer.
  第一次启动时要先装学科包，再提供这门课的 SCSA 真题 PDF（版权原因不随程序分发），题库在你的电脑上建立。
- Class lists, marks and students' scripts stay on your computer.
  班级名单、成绩和学生答卷都保存在你的电脑上。

The user guide (中文 / English) is in the installed folder: `docs/user-guide.md`.
使用指南（中英双语）在安装目录的 `docs/user-guide.md`。
